FAQ

Questions, answered.

Is MotionSaas completely free?

Yes! MotionSaas is 100% free to download and use for all your personal, client, and commercial projects without restrictions.

Which version of After Effects do I need?

MotionSaas works smoothly with Adobe After Effects 2020, 2021, 2022, 2023, 2024, 2025, and 2026+.

Does it work on Mac and Windows?

Yes. MotionSaas runs natively on both macOS (including Apple Silicon M1/M2/M3/M4 and Intel) and Windows 10/11.

How do I install MotionSaas?

Download the MotionSaaS.zip package from this site, unzip it, and double-click Install on Windows.bat (on Windows) or Install on Mac.command (on Mac). Then restart After Effects and open Window > Extensions > MotionSaaS.

Do I need GitHub or coding knowledge?

No. You can download the complete extension directly from the website with one click. The installer handles setup automatically.

Do I need any expression or coding skills to use it?

No. Every tool is applied visually directly from the panel with one click — no expressions or manual keyframing required.
